# Pixel Sprout

Pixel Sprout is original procedural pixel art created for Codex Pet Desktop. The package contains
no third-party character artwork, sound, logo, font, or game resource. Run
`node scripts/generate-original-pet-assets.mjs` from the repository root to reproduce its PNG
preview and sprite sheets.
